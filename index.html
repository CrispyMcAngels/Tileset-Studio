Come importare in HMA

  1. Apri la ROM in HexManiacAdvance.
  2. Se il campo "Mappa HMA" era vuoto, apri prima nell'editor mappe la mappa di destinazione.
  3. Torna alla vista esadecimale (la griglia di byte): nell'editor mappe usa la freccia Indietro. Se trascini sulla mappa, HMA apre il file come se fosse una ROM e non succede niente.
  4. Trascina il file .hma sulla finestra. Mentre lo trascini deve comparire la descrizione dello script ("Tileset Studio - importa…"): se non compare, sei nella vista sbagliata.
  5. Scegli nel dialogo (solo questa mappa / tutte / annulla), poi controlla la mappa. Ctrl+S salva, Ctrl+Z annulla tutto.

Se avevi già trascinato il file sulla mappa, chiudi senza salvare la scheda che HMA ha aperto con il nome del file .hma.
